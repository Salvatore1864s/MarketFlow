
# MarketFlow

MarketFlow — учебный проект маркетплейса, в котором покупатели могут находить товары, оформлять заказы и отслеживать их состояние, а продавцы — размещать товары и управлять продажами.

Проект разрабатывается в рамках учебной практики на продвинутом уровне сложности.

## Технологический стек

- C# / ASP.NET Core
- React + Vite
- PostgreSQL
- Entity Framework Core
- YARP API Gateway
- RabbitMQ
- Redis
- SignalR
- JWT
- Docker Compose
- xUnit
- GitHub Actions
