## Риски

1. Сложность межсервисного взаимодействия.
   Решение: сначала реализовать основной сценарий заказа, затем расширять систему.

2. Ошибки конфигурации Docker.
   Решение: проверять каждый контейнер отдельно.

3. Недостаток времени.
   Решение: сокращать второстепенные функции интерфейса, не исключая обязательные инженерные требования.

4. Ошибки при реализации Saga и Outbox.
   Решение: выделить отдельные тесты на успешное выполнение и компенсацию заказа.
