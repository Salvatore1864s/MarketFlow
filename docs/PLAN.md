## Риски

1. **Сложность взаимодействия сервисов.**
   Решение: разделить систему на отдельные сервисы и использовать RabbitMQ для обмена сообщениями.

2. **Ошибки при работе с Docker.**
   Решение: проверять запуск контейнеров и подключение к базам данных.

3. **Недостаток времени.**
   Решение: сначала выполнять обязательные требования, затем улучшать дополнительные части проекта.

4. **Ошибки при оформлении заказа.**
   Решение: проверять успешное оформление, отмену заказа и возврат зарезервированного товара.

5. **Повторная обработка сообщений.**
   Решение: добавить проверки, чтобы повторные команды не изменяли остатки товара несколько раз.
